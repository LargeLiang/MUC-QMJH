# SEM 探索性路径分析（2026-09-21）

根据本次修订要求，保留 SEM 的探索性尝试，在当前冻结样本上重新构建**观测变量广义路径模型**：格式方程采用线性回归，二元选择方程采用 Logistic 回归。该分析是 SEM 框架下的分方程路径分析，不含潜变量或测量模型，也不是对旧连续正态 SEM 的直接重跑。

## 数据与设定

- 数据：`Data/analysis_data/integrated-20260920/analysis_data.parquet`，108,154 条唯一会话记录；明确胜负 78,959 对。英语 42,001 对，单轮 67,608 对，子集相互重叠。
- 长度指标 L：A/B token 数比的对数；格式 M：标题、列表、粗体的每千 token 密度 A 减 B。四项均按各子集均值和总体标准差标准化。
- 三个格式方程：`M_k = α_k + a_k L + γ_k X + 模型身份对比项 + ε_k`。
- 选择方程：`logit P(A胜) = α + c L + Σ b_k M_k + γ X + 模型身份对比项`。
- 控制项与主分析一致：输入长度、轮数、任务标记、七种提示词属性、语言和模型身份对比；不使用由同一样本胜负构造的能力代理。
- 三个格式残差允许相关，导出残差相关矩阵；不设定格式间的有向路径。所有路径均事后探索，没有按显著性删选列表。

## 估计与解释

各方程分别估计，使用以配对为独立单位的跨方程 HC0 夹心协方差。联合协方差保留 a、b 估计之间的相关性，避免将来自相同记录的系数视为独立。标准化尺度固定为观察样本值；区间条件于该尺度。未处理重复用户或提示词聚类。

`paths.csv` 为七条路径×三个子集的系数、HC0 标准误、逐项正态近似区间及 21 项共同 Holm 校正。长度→格式系数是标准化线性斜率；指向选择的系数是 log-odds 系数。CSV 中极小 p 值可能下溢为零，`log_p_value` 保留其对数信息；文稿统一写为 p<0.001，而非 p=0。

`path_products.csv` 报告 a_k b_k，使用联合渐近正态分布进行 50,000 次参数模拟，随机种子为 20260921，取 2.5% 与 97.5% 分位数。**这是 Monte Carlo 模拟区间，不是记录重采样 Bootstrap；区间逐项、未作多重校正。**

系数乘积仅表示给定方向和方程设定下的候选关联通路。它不是概率变化、自然间接效应或因果中介比例。Logistic 模型存在非线性及非可折叠性，不把 c+Σab 宣称为约简模型的总效应，不计算“中介占比”。路径方向没有时间先后或干预识别，反向/替代方向也可能解释相关结构；本次未开展方向比较。

## 已完成结果

全量样本的长度→标题、列表、粗体斜率分别为 0.154134、0.135697、0.139067。控制长度及其他变量后，标题、列表、粗体→选择系数分别为 0.027827、−0.012930、0.054112；长度→选择系数为 0.482172。最后四项与冻结 Logistic 主分析一致，不是独立验证。

格式密度含长度分母，长度与格式间的关联可能受测量构造影响；尚缺乏内容质量测量、计数/密度替代、非线性、方向替代及聚类敏感性分析。这里不报告 CFI/TLI/RMSEA：分方程 OLS/Logistic 估计没有提供共同协方差结构检验，不能拼接旧 SEM 拟合指标。

## 与旧 SEM 的关系

旧 C23 的 78,970 条样本、胜率能力代理、连续型结果处理及 5,000 次 Bootstrap 结果仍作为历史探索记录保存。新分析不覆盖旧档案，不撤销旧推断撤回的记录，也不将旧区间与新系数混用。当前主流程和 `CURRENT_RESULTS.json` 保持原样，新增结果在本目录独立追踪。

## 复现与检查

在仓库根目录运行 `python Revision/exploratory_paths.py`。环境版本、输入和脚本 SHA-256、输出 CSV 哈希见 `manifest.json`。

执行时已核验冻结输入哈希、样本唯一性、设计矩阵满秩、结果方程收敛及与冻结主结果数值一致；联合协方差各对角标准误与 statsmodels 的 HC0 结果一致，并检查半正定性。模拟抽样及全部三组拟合已完成。此类数值检查不能替代模型设定有效性检验。

方法参考：[lavaan 模型语法](https://lavaan.ugent.be/tutorial/syntax1.html)、[分类内生变量说明](https://lavaan.ugent.be/tutorial/cat.html)、[statsmodels 夹心协方差源码](https://github.com/statsmodels/statsmodels/blob/main/statsmodels/stats/sandwich_covariance.py)。分类变量说明支持对二元结果专门建模；本次实际使用的是 statsmodels 分方程估计，没有使用 lavaan/WLSMV。
